# ELV — "letöltés igen, hasznosítás nem":
#
#   1. A LETÖLTÉS (crawl) engedélyezett. Ezért NINCS itt "Disallow: /" az
#      általános botokra. Ez szándékos: amit a robots.txt kizár, azt a robot
#      LE SEM TÖLTI, így a noindex fejlécet és metát sem látja — és az URL a
#      máshonnan mutató linkek alapján címként mégis bekerülhet az indexbe.
#      Az indexelést tehát nem itt, hanem a válaszfejlécben (X-Robots-Tag,
#      lásd .htaccess) és a lapok <meta name="robots"> sorában tiltjuk.
#
#   2. Az AI-tanító, AI-kereső (GEO) és SEO-elemző botok viszont nem
#      indexelnek, hanem betanítanak, kivonatolnak vagy adatot gyűjtenek —
#      nekik a letöltés sem kell. Ezek NÉV SZERINT tiltva vannak lent.
#      A robots.txt csak kérés, ezért a .htaccess ugyanezt a névsort
#      403-mal is elzárja. A kettőt EGYÜTT kell karbantartani.
#
# ÉLESÍTÉSKOR (okoth.hu, amikor indexelhető lesz):
#   - a .htaccess X-Robots-Tag blokkját vedd ki,
#   - a lapok <meta name="robots"> sorát cseréld "index, follow"-ra,
#   - ide vedd fel:  Sitemap: https://okoth.hu/sitemap.xml
#   Az alábbi AI/SEO-tiltó blokkok élesben is MARADNAK.
